# 🏪 Store Management System

## 📖 Description
The **Store Management System** is a Java-based console application that manages products, suppliers, and customers. It provides inventory tracking, restocking alerts, customer billing, and automatic discount management based on customer type.

## ✨ Features
- Manage products and suppliers
- Add and manage customers
- Track inventory levels
- Automatic stock updates after purchases
- Restocking alerts for low inventory
- Customer billing system
- Automatic discount application

## 🛠️ Tech Stack
- **Language:** Java  
- **Interface:** Console-based application  

 ⚙️ Functionality
- Add new products and customers
- Update stock levels after each purchase
- Apply discounts automatically based on customer type
- Generate bills for customer purchases

## ▶️ How to Run
1. Install Java (JDK 8 or later)
2. Clone this repository:
   ```bash
   git clone https://github.com/your-username/store-management-system.git
````

3. Navigate to the project directory:

   ```bash
   cd store-management-system
   ```
4. Compile the program:

   ```bash
   javac *.java
   ```
5. Run the application:

   ```bash
   java Main
   ```
